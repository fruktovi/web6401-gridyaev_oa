# Лабораторная работа № 2

## Тема
Многостраничный сайт магазина спортивного питания.

## Страницы
- `index.html` — главная страница;
- `catalog.html` — каталог товаров и таблица цен;
- `about.html` — информация о магазине и контакты;
- `style.css` — стили всех страниц.

## Технологии
Используются HTML5 и CSS3.

## Что реализовано
- 3 HTML-страницы;
- ссылки между страницами;
- изображения;
- блочные и строчные элементы;
- таблица товаров;
- отдельный CSS-файл;
- селекторы по тегу (`body`, `header`), классу (`.button`) и псевдоклассу (`:hover`);
- цвета и разные виды выравнивания в таблице: слева, по центру и справа.

Изображения сгенерированы. Цены и контакты демонстрационные.

# Лабораторная работа №3

## Тема
Изучение основ JavaScript: реализация набора базовых функций.

## Структура проекта
Исходные файлы размещены в каталоге `lab3/`:
- `src/core.js` — реализация функций задания (работа с типами данных, побитовые операции, циклы, рекурсия, замыкания, глубокое сравнение объектов);
- `src/core.spec.js` — набор модульных тестов для автоматической проверки корректности функций.

## Выполненные задачи
1. Развернут каркас проекта на базе `teach-kirshdv/js-tasks`.
2. Реализованы функции в соответствии со спецификацией:
   - `isInteger` (проверка целого числа через побитовые операторы);
   - `even` (генерация массива четных чисел);
   - `sumTo`, `recSumTo` (вычисление суммы циклом и рекурсией);
   - `factorial` (вычисление факториала);
   - `isBinary` (проверка степени двойки через побитовое умножение);
   - `fibonacci` (итеративное вычисление N-го числа Фибоначчи);
   - `getOperationFn`, `sequence` (функции высшего порядка и замыкания);
   - `deepEqual` (рекурсивное глубокое сравнение объектов).
3. Пройдено тестирование всех сценариев командой `npm test`.
