# Лабораторная работа № 2

## Тема
Многостраничный сайт магазина спортивного питания.

## Страницы
- `index.html` — главная страница;
- `catalog.html` — каталог товаров и таблица цен;
- `about.html` — информация о магазине и контакты;
- `style.css` — стили всех страниц.

## Технологии
Используются HTML5 и CSS3.

## Что реализовано
- 3 HTML-страницы;
- ссылки между страницами;
- изображения;
- блочные и строчные элементы;
- таблица товаров;
- отдельный CSS-файл;
- селекторы по тегу (`body`, `header`), классу (`.button`) и псевдоклассу (`:hover`);
- цвета и разные виды выравнивания в таблице: слева, по центру и справа.

Изображения сгенерированы. Цены и контакты демонстрационные.
